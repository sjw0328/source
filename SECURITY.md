# Security Policy

## 보안 취약점 신고 / Reporting a vulnerability

보안 취약점은 공개 Issue 에 올리지 말고 아래 중 하나로 비공개로 알려 주세요.

- GitHub 저장소의 **Security → Report a vulnerability** (비공개 신고)
- 이메일: seodes105@gmail.com

Please do not open a public issue for security problems. Use GitHub private vulnerability reporting or the email above.

## 지원 버전 / Supported versions

최신 릴리스만 수정합니다. Only the latest release receives fixes.
