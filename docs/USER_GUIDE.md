# OMEGA X 사용 안내서 / User Guide

왼쪽 메뉴 순서대로 설명합니다. 모든 최적화는 끄거나 앱을 종료하면 원래대로 돌아갑니다(예외는 맨 아래 "되돌리지 않는 동작" 참고).

---

## 처음 실행

1. `python dsafg.py` 또는 빌드한 `OMEGA_X.exe` 실행
2. 사용 동의 화면을 읽고 **동의하고 시작** — 거절하면 앱이 종료됩니다
3. 언어는 Windows 언어를 따라 자동으로 정해지며, **설정**에서 바꿀 수 있습니다

관리자 권한은 처음부터 필요하지 않습니다. 최대 부스트처럼 필요한 기능을 누를 때만 UAC 창으로 요청합니다.

## 🏠 홈 (Home)

- 지금 RAM·CPU 사용량과(측정 가능한 PC에서는) CPU 온도
- 상태 검사·실행 중인 앱·저장소·자동 부스트로 가는 바로가기
- 현재 시스템 상태에 따른 추천

## ⚡ 자동 부스트 (Auto Boost)

핵심 기능입니다. 버튼을 누르면 켜지고, 다시 누르면 꺼집니다.

| 모드 | 하는 일 | 관리자 권한 |
|---|---|---|
| **안전 부스트** | 지금 쓰는 앱 우선, 안 쓰는 앱 CPU·전력 절약, 메모리 부족 시 가볍게 정리 | 없어도 됨 |
| **최대 부스트** | 위 내용 + 쓰는 앱 종류(게임/작업/창작/브라우저) 감지 후 맞춤 조정, 디스크·소리 우선 처리, 고성능 전원 계획 | 권장 |

화면에 보이는 것:
- **절전 중인 앱 / 백그라운드 부하** — 실제로 측정한 값
- **판정 문장** — 일부 앱을 비교군으로 남겨 두고 비교해 효과가 있었는지 표시. 표본이 모자라면 "측정 중"이라고 나옵니다
- **감지된 앱 → 적용 중인 프로필**
- **이 PC에서 배운 것** — 효과가 없던 작업은 스스로 중단합니다. **배운 것 지우기**로 초기화
- **실제로 실행한 작업** — 실행·건너뜀 기록. **로그 복사**로 내보낼 수 있습니다

끄면 절전 모드·우선순위·전원 계획을 전부 원래대로 돌립니다.

## 💾 저장소 (Storage)

1. **정크 파일 스캔** — 사용자 임시 폴더, 최근 파일 목록, Edge·Chrome 캐시 크기 확인
2. **정리하기** — 사용자 임시 폴더(%TEMP%)에서 24시간 지난 파일만 삭제. 확인 창이 먼저 뜹니다
3. **휴지통 비우기** — 항목 수와 용량을 보여준 뒤 확인을 받습니다

정리 전에 브라우저를 닫아 주세요. 삭제한 파일은 휴지통을 거치지 않아 복구할 수 없습니다.

## 📦 앱 및 작업 (Apps & Tasks)

**실행 중 프로세스**
- 이름 검색, 열 머리글 클릭으로 정렬
- **부스트**(5초간 우선순위 올림) / **억제**(10초간 낮춤) / **종료**(확인 후 강제 종료)
- Windows 시스템 프로세스는 버튼이 표시되지 않습니다

**시작 프로그램**
- **비활성화** — 지우기 전에 백업을 남깁니다
- 아래 "OMEGA X 가 제거한 항목"에서 **되돌리기**로 복원

## 🩺 시스템 상태 (Health)

- 100점 만점 종합 점수와 CPU·RAM·디스크·가동 시간별 점수
- 감지된 문제와 추천
- **메모리 누수 감지** — 메모리를 계속 붙잡고 놓지 않는 앱 표시

## 📊 보고서 (Reports)

- **세션 기록** — 최근 30일 요약과 최근 실행 목록, CSV 내보내기
- **시스템 상태 보고서**(HTML), **성능 이력**(CSV), **시작 프로그램 보고서**(HTML) — 바탕화면에 저장됩니다

## ⚙ 설정 (Settings)

- **언어**: 한국어 / English
- **테마**: 라이트 / 다크 / Windows 설정 따름
- **열 관리**: CPU 온도 표시. "뜨거우면 스스로 속도 낮추기"를 켜면 기준 온도를 넘을 때 CPU 최대 속도를 단계적으로 낮췄다 되돌립니다(기본 꺼짐)
- **자동 옵티마이저**: 백그라운드 자동 조정 켜기/끄기
- **스마트 자동화**: 게임 실행 시 최대 부스트 자동 시작, 배터리 사용 시 절전, 예약 실행
- **모든 변경사항 되돌리기**: 지금 걸려 있는 최적화를 즉시 원복
- **업데이트 확인**, **시스템 정보 복사**, **진단 정보 복사**, 라이선스 정보

## 되돌리지 않는 동작

- 최대 부스트 첫 실행 시 Windows 게임 녹화(GameDVR) 끄기 — Windows 설정 > 게임 > 캡처에서 다시 켤 수 있음
- 사용자가 직접 실행한 임시 파일 삭제, 휴지통 비우기, 프로세스 종료

## 저장되는 파일

`%APPDATA%\OMEGA_X\` 아래에 설정, 세션 기록, 학습 결과, 오류 로그, 실행 기록이 저장됩니다. 이 폴더를 지우면 초기화됩니다. 외부로 보내는 데이터는 없습니다(업데이트 확인 제외).

## 문제가 생기면

- 오류 로그: `%APPDATA%\OMEGA_X\error.log`
- 업데이트 로그: `%TEMP%\omega_update.log`
- 신고: [GitHub Issues](https://github.com/sjw0328/source/issues)
